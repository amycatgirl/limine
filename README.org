* Development
Load ~limine.asd~ using your favourite REPL wrapper and load the system:
#+begin_src lisp
  (ql:quickload :limine)
#+end_src

Then run the program by calling it's entrypoint:
#+begin_src lisp
  (limine:main)
#+end_src
